# 📂 Metodologia PARA

Criada por Tiago Forte (Building a Second Brain), o modelo PARA divide todas as informações em 4 categorias de acordo com a acionabilidade:

1. **Projects**: Esforços de curto prazo com objetivo definido. Ex: [[Projeto Echo]].
2. **Areas**: Responsabilidades contínuas sem prazo final.
3. **Resources**: Tópicos ou temas de interesse contínuo.
4. **Archives**: Itens inativos guardados para histórico.
