# ✍️ Boas Práticas de Anotação

Dicas para manter o seu cofre limpo e de alto valor:

1. **Título como declaração**: Sempre que possível, coloque títulos claros e concisos.
2. **Adicione sempre um link de retorno**: Toda nota deve apontar para pelo menos um MOC (ex: [[MOC - Índice Geral]]).
